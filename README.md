Descripción del Programa

Aplicación de consola desarrollada en C# que implementa el uso de funciones con paso de parámetros y retorno de resultados para resolver cálculos geométricos básicos (áreas de figuras) y evaluación lógica (verificación de mayoría de edad), aplicando principios de usabilidad e interacción clara con el usuario en consola.

Análisis del Programa (Entrada, Proceso y Salida)

1. Datos de Entrada

Los valores solicitados al usuario mediante la consola según la opción o función invocada:

Triángulo: Base (baseTriangulo) y altura (alturaTriangulo).

Cuadrado: Longitud del lado (ladoCuadrado).

Círculo: Longitud del radio (radioCirculo).

Verificación de Edad: Edad de la persona en años (edad).

2. Datos que Procesa

Las operaciones matemáticas y lógicas ejecutadas dentro de cada función declarada:

Área del Triángulo: $\text{Área} = \frac{\text{base} \times \text{altura}}{2}$

Área del Cuadrado: $\text{Área} = \text{lado} \times \text{lado}$ (o $\text{lado}^2$)

Área del Círculo: $\text{Área} = \pi \times \text{radio}^2$

Evaluación de Edad: Comparación condicional (edad >= 18) para determinar el estado de mayoría o minoría de edad.

3. Datos de Salida

Resultados retornados por cada función y mostrados en pantalla:

Valor numérico correspondiente al área del triángulo.

Valor numérico correspondiente al área del cuadrado.

Valor numérico correspondiente al área del círculo.

Mensaje de texto indicando si el usuario es "Mayor de edad" o "Menor de edad".
